- Core reference: [`skills/swiftui-sdk-component/references/six-foundations.md`](skills/swiftui-sdk-component/references/six-foundations.md).
- Use [`skills/swiftui-sdk-component/references/`](skills/swiftui-sdk-component/references/) for API design, state ownership, samples, and shipping.
- Human index: [`COMPONENT-CHECKS.md`](COMPONENT-CHECKS.md).

**Not for app screens.** For feature scaffolding (ViewModel, UseCase, layers), use the **swiftui-architecture** skill instead.
